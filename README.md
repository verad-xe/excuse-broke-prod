The excuse: the agent has already written the postmortem, and it blames the human — very convincingly.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/excuse-broke-prod-out python3 main.py
cat /tmp/excuse-broke-prod-out/entry.txt
```

The program writes a single line of at most 180 characters to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
